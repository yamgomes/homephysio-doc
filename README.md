# HomePhysio Doc

Painel profissional em Angular 22 e Optimus UI 2 (OpenPrime). Requer Node.js compatível com Angular 22 (por exemplo, Node 24.15 ou superior na linha 24).

```sh
npm install
npm start
```

Acesse o endereço informado pelo Angular CLI. Execute `npm test -- --watch=false` para os testes e `npm run build` para compilar.

Este é um protótipo de demonstração: não insira dados reais de pacientes. As atividades são mantidas no armazenamento local do navegador e podem ser exportadas como JSON; ainda não há autenticação, integração com Firebase nem envio para o cliente dos jogos. Os arquivos do protótipo anterior estão em `legacy-static`.
