# HomePhysio Doc

Painel profissional em Angular 22 e Optimus UI 2 (OpenPrime). Requer Node.js compatível com Angular 22 (por exemplo, Node 24.15 ou superior na linha 24).

```sh
npm install
npm start
```

Acesse o endereço informado pelo Angular CLI. Execute `npm test -- --watch=false` para os testes e `npm run build` para compilar.

O painel usa a conta do profissional com e-mail verificado. Cadastre o paciente, configure a terapia e entregue o código exibido. O paciente acessa pelo código no cliente dos jogos. Os resultados ainda ficam no dispositivo. Para instalar as dependências, mantenha este projeto ao lado de virtualter-3.
