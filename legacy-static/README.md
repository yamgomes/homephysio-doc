# HomePhysio — painel profissional

Protótipo local para configurar atividades fictícias de ombros e surfe. Abra `index.html` em um servidor local, por exemplo `npx serve .`, ou use uma extensão de servidor estático.

Os planos são salvos no `localStorage` e podem ser exportados como JSON no formato do cliente do jogador. O cliente ainda não importa esses arquivos. Não há autenticação, integração Firebase, vínculo de profissionais e pacientes, visualização de resultados ou prescrição real. Use exclusivamente dados fictícios. A disponibilização real depende da integração e de regras de acesso testadas.
